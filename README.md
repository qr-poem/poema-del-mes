# Poetry QR Project

## Sharing Poetry in Public Spaces

In our fast-paced world, we rarely take time to pause and appreciate art. This project creates unexpected encounters with poetry in public spaces:

1. QR codes are placed in locations where people might have a moment to reflect
2. Scanning the code opens a beautifully designed page displaying a poem
3. The experience is designed to be simple, beautiful, and momentary

## Project Concept

This project creates a GitHub Pages website that displays carefully selected poems that can be accessed through QR codes placed in bars, restaurants, terraces, and other public spaces. The initiative aims to bring moments of joy, reflection, and beauty into everyday life through poetry.

## Technical Details

The website is built with:
* React 18.3.1
* GitHub Pages for hosting
* Responsive design for optimal viewing on mobile devices
* Minimalist interface that focuses on the poem content

## Supporting Authors

This is a non-profit initiative that fully supports and respects the work of poets. 

If you enjoy them, please support the authors by purchasing their publications, preferably from a physical bookstore.

## Setup and Development

### Prerequisites
* Node.js (v16 or higher)
* npm or yarn

### Local Development

```bash
# Clone the repository
git clone https://github.com/qr-poem/poema-del-mes.git

# Navigate to the project directory
cd poema-del-mes

# Install dependencies
npm install

# Start the development server
npm start
```

## Deployment

The site automatically deploys to GitHub Pages when changes are pushed to the main branch.
